# Usability Test Plan: EcoSync App

## 1. Executive Summary
This document outlines the methodology and scenarios for conducting a remote usability test on the EcoSync mobile app prototype. The focus is on the core user journeys: onboarding, logging an action, and viewing analytics.

## 2. Participant Profile
* **Target Audience:** Tech-savvy individuals interested in sustainability.
* **Sample Size:** 5 Participants.
* **Recruiting:** Sourced via internal user panels and social media screeners.

## 3. Test Environment
* **Format:** 1-on-1 Moderated remote testing via Zoom.
* **Prototype:** Interactive Figma prototype (Mobile viewport).
* **Duration:** 30-45 minutes per session.

## 4. Tasks & Scenarios

### Task 1: Account Creation & Onboarding
* **Scenario:** "You've just downloaded EcoSync to help track your carbon footprint. Please open the app and set up your new account."
* **Completion Criteria:** User successfully reaches the main dashboard after completing the 3-step onboarding questionnaire.

### Task 2: Logging a Sustainable Action
* **Scenario:** "You biked to work today instead of driving. Show me how you would log this activity in the app to earn your daily points."
* **Completion Criteria:** User navigates to the 'Log' screen, selects 'Transportation > Biking', enters the distance, and submits.

### Task 3: Finding the Weekly Report
* **Scenario:** "You want to see how you've done this week compared to last week. Where would you go to find your carbon savings report?"
* **Completion Criteria:** User locates the 'Analytics' tab in the bottom navigation and successfully opens the weekly summary.

## 5. Metrics & Data Collection
* **Quantitative:** Time to completion, Task success rate (Binary: Yes/No), Non-critical and critical errors.
* **Qualitative:** Participant quotes, signs of frustration, general feedback via post-task questions.
