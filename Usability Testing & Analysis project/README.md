## 📌 Project Overview
This repository contains a comprehensive Usability Testing and Analysis project for **EcoSync**, a fictional mobile application designed to help users track their daily carbon footprint and adopt sustainable habits. 

The goal of this project is to demonstrate end-to-end usability testing processes, including planning, moderation, data collection, metric analysis, and actionable UX recommendations.

## 🗂 Repository Structure
* `/docs/` - Contains the Usability Test Plan, Scenarios, Moderator Script, and Consent Forms.
* `/data/` - Contains the raw observational data and usability metrics (Task Success Rate, Time on Task, SUS scores) in an Excel format.
* `/reports/` - Contains the final polished Usability Findings Report (PDF).

## 🎯 Objectives
1. Identify friction points in the app's onboarding flow.
2. Evaluate the ease of logging a new "sustainable action."
3. Assess the discoverability of the weekly progress dashboard.

## 🔬 Methodology
* **Test Type:** Moderated, remote usability testing (Think-Aloud Protocol).
* **Participants:** 5 participants matching the target demographic (Ages 18-35, eco-conscious but not experts).
* **Metrics Tracked:** * Task Success Rate
  * Time on Task
  * Error Rate
  * System Usability Scale (SUS) Score

## 🚀 How to Use This Repository
You can use this project as a template for your own UX research projects. The Markdown files can be adapted for new products, and the Excel template provides a standard format for tracking usability metrics.
